# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：
1. **预处理**：处理所有以 `#` 开头的指令。`#include` 把头文件内容直接复制进来，`#define` 做文本替换，同时去掉注释。这个阶段只操作文本，不检查语法。产物是 `.i` 文件，体积通常比源码大很多。

2. **编译**：把预处理后的代码翻译成汇编语言。gcc 会检查语法错误，如果有错就在这一阶段报错。产物是 `.s` 文件，里面是平台相关的汇编指令。

3. **汇编**：把汇编指令翻译成机器能识别的二进制代码。产物是 `.o` 目标文件，里面已经是机器码，但还不能直接运行——因为它引用的外部函数（比如其他文件里的函数）还没找到具体实现。

4. **链接**：把多个 `.o` 文件和必要的库文件拼在一起，解决跨文件的函数调用。链接器把各个目标文件里的"欠条"（未定义符号）和"正主"（函数实现）配对，最终生成可执行文件。
